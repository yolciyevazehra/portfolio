Qısa məlumat

Mən Zəhra Yolçiyeva, frontend development sahəsində inkişaf edən və rəqəmsal məhsullar yaratmağa maraq göstərən developerəm. Texnologiya, dizayn və problemlərə yaradıcı həllər tapmaq mənim əsas maraq dairəmə daxildir. İşə yanaşmam daim öyrənmək, detallara diqqət etmək və hər layihədə həm funksional, həm də istifadəçi yönümlü nəticə ortaya qoymaq üzərində qurulub.

İndiyə qədər portfolio, landing page və e-commerce layihələri üzərində işləmişəm. Bu layihələrdə responsive və istifadəçi yönümlü interfeyslər hazırlayaraq əsasən HTML, CSS, JavaScript və Tailwind CSS-dən istifadə etmişəm. Komanda daxilində ideyaların müzakirəsinə, məsuliyyətlərin bölüşdürülməsinə və ortaq məqsədə yönəlmiş əməkdaşlığa önəm verirəm. Hazırda React və backend texnologiyaları üzrə biliklərimi genişləndirərək full-stack development istiqamətində inkişaf etməyi hədəfləyirəm.
